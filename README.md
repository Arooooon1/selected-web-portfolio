# Selected Web Portfolio

Три самостоятельных интерактивных сайта с разным визуальным характером. Два на русском, один полностью на английском.

**Стек:** HTML, CSS, JavaScript, GSAP. Корзины, избранное, заявки и изменения админок сохраняются в LocalStorage.

## Открыть

Скачай репозиторий и открой `index.html` в браузере. Установка зависимостей и сервер не нужны.

Общая витрина: [web/selected/index.html](web/selected/index.html). В ней можно переключать превью сайтов, админок и мобильных версий.

## RIFTLINE

Сайт киберспортивного клуба: состав и профили игроков, матчи и результаты, сохранение события в календарь, новости, мерч с размерами, корзина и кабинет болельщика.

В админке: игроки, матчи, товары, материалы, заказы и заявки.

[Исходники сайта](web/11.%20RIFTLINE%20-%20Esports%20Club/)

![RIFTLINE](web/11.%20RIFTLINE%20-%20Esports%20Club/preview-desktop.png)

## OBJECTORY

Магазин светильников, керамики и постеров: категории, поиск, сортировка, галерея, варианты исполнения, избранное, корзина, оформление заказа и журнал.

В админке: предметы, остатки, заказы, публикации и обращения.

[Исходники сайта](web/12.%20OBJECTORY%20-%20Design%20Store/)

![OBJECTORY](web/12.%20OBJECTORY%20-%20Design%20Store/preview-desktop.png)

## STILLFRAME

Англоязычный каталог локаций для съёмок: фильтры, подборки с заметками и экспортом, календарь доступности, расчёт стоимости, заявки и кабинет продакшена. Пересекающиеся даты активных заявок блокируются.

В админке: локации, заявки на съёмку и обращения владельцев пространств.

[Исходники сайта](web/13.%20STILLFRAME%20-%20Location%20Library/)

## Структура

- `index.html` — вход в общую подборку.
- `web/selected/` — витрина, описание и результаты проверки.
- `web/11. RIFTLINE - Esports Club/` — первый сайт.
- `web/12. OBJECTORY - Design Store/` — второй сайт.
- `web/13. STILLFRAME - Location Library/` — третий сайт.
- `web/portfolio-source/` — редактируемые стили, сценарии и сборщик трёх HTML-файлов.

Чтобы пересобрать сайты после изменения исходников, запусти из корня репозитория:

```sh
node web/portfolio-source/build.mjs
```

## Проверка

Проверены 53 страницы и состояния на экранах 1440 × 1000 и 390 × 844. Проверка включала изображения, отсутствие горизонтального вылезания страниц, обработчики кнопок, корзины, заказы, статусы, редактирование данных, экспорт и доступность дат.

Подробный отчёт: [verification.json](web/selected/verification.json). Превью сайтов и админок — реальные снимки интерфейса.

## Демонстрационный режим

Это проекты для портфолио, а не сайты реальных клиентов. Бренды, участники, товары и локации вымышлены. Данные каждого посетителя хранятся только в его браузере; общего сервера, защищённой авторизации, оплаты, рассылки и реального бронирования нет. Админки открыты для демонстрации возможностей.

Шрифты и изображения находятся в папках сайтов. Лицензии шрифтов — рядом с файлами шрифтов; библиотека GSAP содержит заголовок лицензии.
