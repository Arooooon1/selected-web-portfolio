# Selected Web Portfolio

Четыре интерактивных сайта с разным визуальным характером. **SAVAGE — главная работа подборки**, затем RIFTLINE, OBJECTORY и STILLFRAME.

## Как посмотреть

1. Нажми **Code → Download ZIP** и распакуй репозиторий.
2. Открой корневой [index.html](index.html) в браузере: он переведёт в общую витрину [web/selected/index.html](web/selected/index.html).
3. Нажми «Открыть сайт» под работой. Переключатели «Сайты», «Админки» и «На телефоне» меняют превью.

Установка, сборка и сервер для просмотра не нужны. GitHub показывает исходный HTML как код; запускай скачанные файлы в браузере.

## 01 / SAVAGE — главная работа

[Папка сайта и инструкция](web/14.%20SAVAGE%20-%20Gaming%20Gear/) · [LIGHT LAB: запись работы](web/14.%20SAVAGE%20-%20Gaming%20Gear/light-lab-preview.mp4) · [Редактируемые исходники](web/savage-source/)

Концепт бренда игровых устройств в палитре графит, титан и оранжевый. Русский и английский интерфейсы, английские названия моделей, 24 устройства в восьми категориях. Прокрутка раскрывает конструкцию клавиатуры; витрину можно листать и открывать карточки моделей. Работают поиск, фильтры, сортировка, сравнение и корзина.

В **LIGHT LAB** можно вращать объёмную клавиатуру, мышь и наушники, рассматривать их со всех сторон, менять цвет, яркость, скорость и пять режимов подсветки. SYNC объединяет устройства в одну сцену. Световой профиль сохраняется в браузере.

Обновлённая версия включает заново собранные мышь и наушники, более подробную клавиатуру, студийные отражения и сканированные текстуры кожи. Все материалы находятся внутри папки сайта и работают без интернета. [Описание доработки 3D](web/14.%20SAVAGE%20-%20Gaming%20Gear/design/3D-REFINEMENT.md).

## Сборка и проверки

Стек: **HTML, CSS, JavaScript**. Для анимаций используется GSAP, для LIGHT LAB — локальная Three.js 0.160.1. Готовые сайты уже собраны. Для пересборки нужен Node.js:

```sh
node web/savage-source/build.mjs
node web/portfolio-source/build.mjs
```

[Проверка подборки](web/selected/showcase-verification.json) фиксирует порядок работ, ссылки, превью, переключение вкладок, адаптивность и загрузку материалов LIGHT LAB. [Отчёт SAVAGE](web/14.%20SAVAGE%20-%20Gaming%20Gear/verification.json) содержит 117 функциональных проверок и последующие проверки доработки. [Проверка обновлённой 3D-сцены](web/14.%20SAVAGE%20-%20Gaming%20Gear/visual-verification.json) фиксирует загрузку студии и текстур, вращение, разрешение сцены и мобильный вид. [Исходный отчёт трёх сайтов](web/selected/verification.json) сохранён с датой своей проверки.

Для повторного прогона SAVAGE: установи Microsoft Edge и `npm install --no-save playwright`, затем выполни `node web/savage-source/verify.cjs`. Проверка 3D-сцены: `node web/savage-source/verify-visuals.cjs`. Проверка витрины: `node web/selected/verify.cjs`.

## Формат демонстрации

Бренды, модели, цены, игроки и локации вымышлены. Это самостоятельные проекты для портфолио. Данные, корзины и заявки хранятся локально в браузере; общей серверной базы нет. Реальные оплата, доставка, отправка писем и бронирование не подключены. SAVAGE показывает оформление без сохранения персональных данных и не содержит админки.

Для объёмной сцены SAVAGE нужен WebGL. Концепт-модели в LIGHT LAB не являются заводскими CAD-моделями. Эффекты учитывают настройку уменьшения движения.

Лицензии сторонних шрифтов и библиотек находятся рядом с соответствующими файлами в `assets/`.
