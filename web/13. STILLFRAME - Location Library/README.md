# STILLFRAME

A fictional location library for film and photography, with an entirely English interface.

Open `index.html`. The Studio dashboard link is in the footer, or use `#/admin`.

Features: location and budget filters, grid/list views, location details, local availability calendar, multi-day estimates, crew limits, overlapping-date prevention, enquiries, cancellation, project shortlist, production notes, text export, profile and space-owner form.

The dashboard supports creating, editing and deleting locations, publication status, enquiries, inbox records, status changes, search, exports and activity history.

This is a self-contained HTML/CSS/JavaScript portfolio demonstration. Browser LocalStorage holds all data. There is no shared server, secure authentication, payment, email delivery or actual property booking. All brands and properties are fictional.

Previews are actual interface screenshots. Collection documentation: `../selected/README.md`.
