# Selected — три сайта для портфолио

Открой `index.html` в современном браузере. Установка, сборка и сервер для просмотра не нужны.

Для переноса подборки сохрани папку `selected` и папки работ 11–13 рядом друг с другом. Каждый сайт также можно переносить отдельно вместе со своей папкой `assets`.

В подборке можно переключать превью сайтов, админок и мобильных экранов. Под каждой работой есть отдельные ссылки на сайт и панель управления.

## Проекты

- **RIFTLINE**, русский интерфейс — киберспортивный клуб: профили игроков и штаба, расписание и результаты матчей, сохранение события в календарь, новости, мерч с размерами, корзина и кабинет болельщика.
- **OBJECTORY**, русский интерфейс — магазин света, керамики и постеров: категории, поиск, сортировка, варианты исполнения, галерея, избранное, корзина, доставка в расчёте и личный кабинет.
- **STILLFRAME**, полностью английский интерфейс — библиотека локаций: фильтры, два вида списка, подробности площадки, подборка с заметками и экспортом, календарь, расчёт съёмки, заявки и кабинет продакшена.

У каждого проекта своя админка: создание, редактирование, удаление, публикация/черновики, статусы, поиск, CSV и история локальных изменений. В STILLFRAME календарь учитывает активные заявки и не принимает пересекающиеся даты.

## Формат и ограничения

- HTML, CSS, JavaScript. Внешний сервер и база данных не используются.
- Изменения, корзины и заявки сохраняются в LocalStorage конкретного браузера. Это локальные демонстрации, общей базы для посетителей нет.
- Авторизации с паролем нет. «Кабинет» показывает локальный профиль и записи, а админка открыта для просмотра возможностей.
- Оплата, реальная доставка, рассылка писем и бронирование реальной недвижимости не выполняются. Формы сохраняют записи на этом устройстве.
- Бренды, игроки, товары, события и локации вымышлены. Это самостоятельные проекты для портфолио, а не выполненные заказы реальных компаний.
- Изображения и шрифты находятся в папках проектов. Эффекты учитывают настройку уменьшения движения; в подвале есть переключатель анимации.
- Начальные данные можно вернуть кнопкой внизу админки. Это удалит локальные изменения этого проекта.

В `verification.json` записаны фактически выполненные проверки. Скриншоты каждой работы находятся рядом с её `index.html`.

Для внесения изменений исходные стили и сценарии лежат в `../portfolio-source/`. После редактирования выполни `node web/portfolio-source/build.mjs` из папки ProjectSale: скрипт обновит три самостоятельных HTML-файла.
