# Studio lighting and leather

- **Studio Small 08** HDRI by Sergej Majboroda, Poly Haven: https://polyhaven.com/a/studio_small_08
- **Leather Red 02**, normal and roughness maps, Poly Haven: https://polyhaven.com/a/leather_red_02
- Asset license: **CC0 1.0**, https://polyhaven.com/license

The original 1K HDR and PNG files are retained beside this document. studio-assets.js packages the same bytes as data so the viewer can run directly from file:// without external network access.

The locally adapted RGBELoader is Three.js r160, released under MIT: https://github.com/mrdoob/three.js/blob/r160/examples/jsm/loaders/RGBELoader.js. The copyright and license are in ../vendor/THREE-LICENSE.txt.

The earlier Fabric Leather 01 study maps are retained as development references and are not loaded by the current viewer.
